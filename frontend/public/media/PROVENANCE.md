# Media provenance (frontend v4)

- `ring-hero.webp`, `ring-hero-m.webp`: rendered from this site's own three.js ring scene (`src/RingScene.tsx`) by
  `scripts/render-hero-still.mjs` (reduced-motion frame, 1440x900 and 390x844 @2x). Shown before the live WebGL scene
  starts; identical framing.
- `up-map.webp`: illustrative Uttar Pradesh map used by the districts page (generated earlier; see git history of
  `design/scrolly/media/images/PROVENANCE.md`). Labelled "Illustrative map" in the UI.

The paper-craft film and its layers used by frontend-v3 are no longer served; they remain in `design/scrolly/media/`.
