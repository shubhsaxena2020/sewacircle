# SewaCrewKit model provenance

All six meshes are original geometry built in Autodesk Fusion by [`SewaCrewKit.py`](../../../design/fusion/SewaCrewKit/SewaCrewKit.py). The script creates one named component per part. Fusion source units are millimetres; its API uses centimetres internally. The script exposes the dimensions as Fusion user parameters.

| Component | Key dimensions | GLB size |
| --- | --- | ---: |
| `volunteer_token` | 18 mm diameter, 5 mm high, 1 mm fillet | 10,988 B |
| `role_slot` | 27 mm diameter, 4 mm high, 1.1 mm recess | 5,032 B |
| `standby_node` | 8 mm diameter, 3 mm high, 0.7 mm fillet | 11,888 B |
| `gap_marker` | 27 mm diameter, 3.2 mm annulus | 5,028 B |
| `ready_seal` | 38 mm diameter, recessed rim | 5,048 B |
| `crew_ring` | 118 mm diameter, six recessed sockets | 9,128 B |

**Total GLB bytes:** 47,112. The local `studio.hdr` is 8,239 bytes and is generated by [`generate-studio-hdr.py`](../../../design/fusion/generate-studio-hdr.py). The ready-state fallback still is captured from the live Three scene at 1440×900 and converted to WebP. No external textures, downloaded models, logos, or emblems are used.

## Export and conversion

The Fusion add-in's startup copy is installed under `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\SewaCrewKit` with `runOnStartup: true`; the committed manifest keeps it off. Set `SEWA_FUSION_OUT` to `design\fusion\exports`, then start Fusion. `result.json` confirms each per-component OBJ export. The script uses `ExportManager.createOBJExportOptions` with `MeshRefinementLow`. Fusion wrote six OBJ files (675,155 bytes total) and companion MTL files. The temporary add-in files were removed after export.

The conversion commands used, one component at a time:

```powershell
npx --yes obj2gltf@3.2.0 -i design\fusion\exports\volunteer_token.obj -o frontend\public\models\volunteer_token.glb -b --inputUpAxis Z --outputUpAxis Y
npx --yes @gltf-transform/cli@4.5.1 optimize frontend\public\models\volunteer_token.glb frontend\public\models\volunteer_token.opt.glb --compress meshopt
```

The same two commands were repeated for `role_slot`, `standby_node`, `gap_marker`, `ready_seal`, and `crew_ring`; each `.opt.glb` replaced its initial `.glb`. `optimize` ran deduplication, welding, simplification, pruning, and meshopt compression. The unoptimized GLBs totalled 217,380 bytes.

The previews in [`docs/screens/v4/models`](../../../docs/screens/v4/models/) were rendered with Three.js by `design/fusion/preview/preview.ts`, captured by `frontend/scripts/capture-model-previews.mjs`, and visually inspected as a gallery and as individual parts.
