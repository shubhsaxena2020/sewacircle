Architecture

Three steps. Deterministic certainty.

From unstructured community briefs to cryptographically verified service records.

01 · INTENT

Open-Weights Role Extraction

Organisers paste raw briefs in Hindi, English or Hinglish. A lightweight local model runs with a 61,000-name Indian gazetteer mask to extract required skills, headcounts, and safety-critical roles without cloud leakage.

Try brief extraction →
02 · ALLOCATION

Deterministic CP-SAT Solver

Instead of heuristic guesswork, OR-Tools CP-SAT solves exact constraints: safety-checked skill verification, travel distance bounds (≤ 25 km), mentor-novice pairing, and a verified standby for every single essential role.

View solver board →
03 · VERIFICATION

Tamper-Evident Contribution Log

After the drive, host notes and check-in logs are cross-referenced with automated inflation checks. Host confirmation commits credentials to an immutable SHA-256 hash chain with W3C credential export.

Inspect hash chain →

Transparency & Principles

What SewaCircle does. And what it never does.

Clear institutional boundaries designed to protect volunteers, hosts, and organizers.

System Guarantees
  • ✓ Safety roles (first aid, driving, disaster) accept only host-checked skills.
  • ✓ Deterministic solver: Always reproducible with identical constraints.
  • ✓ Honest gap reporting: Reports unfilled slots clearly instead of hiding deficits.
  • ✓ Zero cloud telemetry: Runs offline on commodity hardware (0.33s on 500 volunteers).
System Boundaries
  • ✕ No behavioral scoring: Does not predict youth reliability or personality.
  • ✕ No automated commitment: Host review is required for all contribution claims.
  • ✕ No biometric or sensitive tracking: Uses only coarse block-level distance.
  • ✕ Not affiliated with MY Bharat or any government department or ministry.
