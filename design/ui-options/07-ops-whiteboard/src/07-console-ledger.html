What Tampering Looks Like

If an actor attempts to quietly alter Kabir Z.'s claimed hours from 8 to 5 inside a historical draft without recording a host decision, the payload hash changes.

Because each block includes the hash of the preceding block (prev_hash), modifying block #03 immediately breaks the link at block #04, invalidating the entire remaining chain.
